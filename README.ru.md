# Klipper Motor Music

[![English](docs/assets/english.svg)](README.md) [![Русский](docs/assets/russian.svg)](README.ru.md)

![Музыкальные команды M1006 превращаются в три выбираемых голоса моторов](docs/assets/banner.svg)

**Мелодии Bambu Lab через шаговые моторы принтера с Klipper.**
Используй исходные музыкальные блоки `M1006`, выбирай любую комбинацию трёх
голосов и запускай стартовую мелодию до homing с `PRE_HOME=1`.

[![Tests](https://github.com/petrovichest/klipper-motor-music/actions/workflows/tests.yml/badge.svg)](https://github.com/petrovichest/klipper-motor-music/actions/workflows/tests.yml)
[GPL-3.0-or-later](LICENSE) · [Справочник](docs/reference.ru.md) · [Разработка (EN)](docs/development.md) · [Приватность (EN)](docs/privacy.md)

## Возможности

- **Файлы Bambu:** в комплекте штатные мелодии начала и завершения A1.
- **Выбор голосов:** `X`, `Y`, `Z`, `XY`, `XZ`, `YZ` или `XYZ` для каждого запуска.
- **До homing:** включение выбранных моторов, мелодия, затем обычный `G28`.
- **Без динамика и перепрошивки:** один Python-файл использует зависимости Klipper.
- **Проверка без движения:** предпросмотр без включения моторов и генерации шагов.

**Экспериментальная функция для оборудования.** Работа одного и трёх моторов,
включая режим до homing, подтверждена отзывами об Ender-3 Pro. Автоматические
тесты проверяют реальную генерацию шагов Klipper v0.13.0 и `master`. Звук,
сохранение физической позиции и возможности соединения зависят от принтера.
Расширение воспроизводит ноты и ритм через микроколебания STEP/DIR; закрытый
алгоритм управления моторами Bambu и одинаковый тембр оно не воспроизводит.

**Поддерживаются:** моторы XYZ с кинематикой Cartesian. CoreXY, Delta,
экструдеры и оси с несколькими независимыми драйверами не поддерживаются.
Подробности — в [ограничениях](docs/reference.ru.md#ограничения).

## Установка

Выполняй команды на компьютере с Klipper, когда принтер свободен. Если Klipper
или конфигурация находятся в других каталогах, поправь пути.
Если расширение уже установлено, используй [раздел обновления](#обновление-и-удаление),
чтобы не заменить свои настройки шаблоном.

```bash
git clone https://github.com/petrovichest/klipper-motor-music.git ~/klipper-motor-music
ln -s ~/klipper-motor-music/motor_music.py ~/klipper/klippy/extras/motor_music.py
mkdir -p ~/printer_data/config/tunes
cp ~/klipper-motor-music/examples/tunes/*.gcode ~/printer_data/config/tunes/
cp ~/klipper-motor-music/examples/motor_music_3voice.cfg ~/printer_data/config/motor_music.cfg
```

Добавь в `printer.cfg`:

```ini
[include motor_music.cfg]
```

Перезапусти **службу Klipper** через интерфейс принтера или командой:

```bash
sudo systemctl restart klipper
```

Установится полный профиль: голос X → мотор X, Y → Y, Z → Z. Доступны все семь
комбинаций; выбор `VOICES` не выключает голоса в постоянной конфигурации.
Команда создания ссылки намеренно не заменяет уже существующее расширение.

Для первой проверки на одном моторе используй [motor_music.cfg](examples/motor_music.cfg)
вместо полного профиля. В нём настроен **только голос Y Bambu через мотор X**;
остальные голоса недоступны. Подключай один профиль, а не оба сразу.

## Первый запуск

Сначала предпросмотр. Он не требует homing, не включает моторы и не создаёт движения:

```gcode
MOTOR_MUSIC_PLAY FILENAME=a1-start.gcode VOICES=XYZ DRY_RUN=1
```

Чтобы сыграть **до homing**:

```gcode
MOTOR_MUSIC_PLAY FILENAME=a1-start.gcode VOICES=XYZ PRE_HOME=1
G28
```

`PRE_HOME=1` включает выбранные моторы и оставляет их включёнными для `G28`.
Оси не отмечаются как прошедшие homing. Пределы: **3 секунды и один настроенный
микрошаг не более 0.025 мм**. Пока координаты неизвестны, проверить расстояние
до физических упоров невозможно; механика должна свободно совершать эти
небольшие колебания. Для осей с известной координатой проверки сохраняются.

Для обычного воспроизведения сначала выполни homing XYZ и обычную безопасную
парковку внутри рабочей области, затем запускай:

```gcode
MOTOR_MUSIC_PLAY FILENAME=a1-start.gcode VOICES=XYZ
MOTOR_MUSIC_PLAY FILENAME=a1-finish.gcode VOICES=XYZ
```

Это музыкальные файлы, **не задания печати**. Загружай их через `MOTOR_MUSIC_PLAY`.
Импортёр пропускает известную обвязку Bambu, отклоняет команды движения и
нагрева и проверяет весь файл до воспроизведения.

## Выбор голосов

Для сравнения одной мелодии вводи по одной команде:

```gcode
MOTOR_MUSIC_PLAY FILENAME=a1-start.gcode VOICES=X
MOTOR_MUSIC_PLAY FILENAME=a1-start.gcode VOICES=Y
MOTOR_MUSIC_PLAY FILENAME=a1-start.gcode VOICES=Z
MOTOR_MUSIC_PLAY FILENAME=a1-start.gcode VOICES=XY
MOTOR_MUSIC_PLAY FILENAME=a1-start.gcode VOICES=XZ
MOTOR_MUSIC_PLAY FILENAME=a1-start.gcode VOICES=YZ
MOTOR_MUSIC_PLAY FILENAME=a1-start.gcode VOICES=XYZ
```

`VOICES` выбирает **исходные музыкальные партии**, а не копии ведущей мелодии.
В стартовой мелодии A1 у X всего **три ноты**, а ведущую партию играет Y.
Паузы и полная длительность сохраняются. В полном профиле имена партий совпадают
с именами физических моторов; другое назначение в конфигурации может это изменить.

Выбор действует только на текущую команду. Без `VOICES` играют все настроенные
партии. Параметр совместим с `PRE_HOME=1` и `DRY_RUN=1`.

## Подключение в слайсере

В `motor_music.cfg` разреши воспроизведение во время задания и выполни `RESTART`
на свободном принтере:

```ini
allow_during_print: True
```

В OrcaSlicer открой **настройки принтера → Машинный G-code**. Для мелодии до
homing поставь вызов перед существующим `G28`:

```gcode
MOTOR_MUSIC_PLAY FILENAME=a1-start.gcode VOICES=XYZ PRE_HOME=1
G28
```

Остальную подготовку печати сохрани. Другой вариант — обычный вызов без
`PRE_HOME` после homing и парковки внутри рабочей области.

В конечном G-code или существующем макросе окончания добавь:

```gcode
MOTOR_MUSIC_PLAY FILENAME=a1-finish.gcode VOICES=XYZ
```

Вызов должен идти **после существующих ретракта, подъёма сопла и выключения
нагревателей, но до финальной парковки на границах осей и до `M84`/`M18`**.
Обычные проверки позиции сохраняются. Если макрос окончания уже играет мелодию,
не дублируй её вызов в слайсере. Голоса для начала и конца выбирай независимо.
Сохрани профиль и **переслайсь модель**.

## Обновление и удаление

```bash
git -C ~/klipper-motor-music pull --ff-only
sudo systemctl restart klipper
```

Обновляй на свободном принтере. G-code `RESTART` перечитывает конфигурацию,
но **не** загружает заново уже импортированный Python-файл; при обновлении кода
нужен перезапуск службы. `git pull` не заменяет скопированную конфигурацию принтера.

Для удаления убери строку include, ссылку на расширение и вызовы мелодий
из слайсера/макросов, затем перезапусти службу Klipper. Обычные команды homing,
парковки, выключения нагревателей и моторов сохрани.
