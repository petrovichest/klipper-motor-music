## Команды

| Команда | Назначение |
|---|---|
| `MOTOR_MUSIC_PLAY FILENAME=a1-start.gcode` | Проверить и воспроизвести музыкальный файл из `tune_directory`. |
| `VOICES=X` / `XY` / `XYZ` | Параметр `MOTOR_MUSIC_PLAY`: непустая комбинация настроенных партий. |
| `PRE_HOME=1` | Параметр `MOTOR_MUSIC_PLAY`: короткая мелодия одним микрошагом до homing с включением выбранных моторов. |
| `DRY_RUN=1` | Параметр `MOTOR_MUSIC_PLAY` или `MOTOR_MUSIC_TEST`: проверка без включения моторов и движения. |
| `MOTOR_MUSIC_TEST VOICE=Y NOTE=46 DURATION=200` | Ля 440 Гц на 200 мс через один настроенный голос. |
| `M1006 S1` … `M1006 W` | Накопить и воспроизвести напрямую; действуют обычные проверки homing и моторов. |
| `MOTOR_MUSIC_CLEAR` | Сбросить накопленную последовательность `M1006`. |

`FILENAME` должен оставаться внутри `tune_directory`. Регистр букв голосов
неважен; повторы, неизвестные буквы и ненастроенные голоса отклоняются. Выбор
не переносит партию на другой мотор и не меняет сохранённый профиль.

У `MOTOR_MUSIC_TEST`: `VOICE` по умолчанию Y; `NOTE` по умолчанию 46,
допустимы 1–72; `DURATION` по умолчанию 200, допустимы 10–1000 **миллисекунд**.
`PRE_HOME` относится к воспроизведению файлов, а не к пробной ноте или прямому `M1006`.

## Конфигурация

| Параметр | По умолчанию | Значение |
|---|---:|---|
| `voice_x`, `voice_y`, `voice_z` | Задаются явно | Партия Bambu → `stepper_x`, `stepper_y` или `stepper_z`. Каждый мотор назначается один раз. |
| `amplitude_steps` | 1 | Максимальное отклонение в настроенных микрошагах; 1–32. |
| `max_frequency` | 1000 | Максимальная частота выбранной ноты, Гц; диапазон настройки 30–2000. |
| `max_excursion` | 0.1 | Максимальное отклонение от исходной позиции, мм; до 0.5. |
| `max_step_rate` | 2000 | Максимальная суммарная частота шагов; до 100000 шаг/с. |
| `max_duration` | 15 | Максимальная длительность файла/последовательности, с; до 30. |
| `position_margin` | 1 | Отступ от пределов оси, мм; не менее 0.1. |
| `allow_during_print` | False | Разрешить музыку во время печати или паузы, включая стартовый код слайсера. |
| `tune_directory` | Каталог config + `/tunes` | Каталог музыкальных файлов. |

[Полный профиль](../examples/motor_music_3voice.cfg) назначает три партии
одноимённым моторам и задаёт `max_step_rate: 3000`. У штатных мелодий начала
и завершения A1 пик составляет примерно 2359 и 2490 шагов/с при амплитуде
один микрошаг. [Профиль одного мотора](../examples/motor_music.cfg) назначает
только Y на мотор X и использует стандартный лимит 2000.

Один настроенный микрошаг равен `rotation_distance / steps_per_rotation`,
с учётом микрошагов и передачи. Для типичной XY-оси с 200 шагами, 16 микро-
шагами и 40 мм на оборот это 0.0125 мм; для Z с 8 мм на оборот — 0.0025 мм.

## Ограничения

- Обычный режим требует homing XYZ, включённых выбранных моторов и парковки внутри рабочей области.
- `PRE_HOME=1` допускает неизвестные координаты, но не подменяет их. Выбранные
  моторы включаются и остаются включёнными. Пределы: 3 секунды, амплитуда 1,
  настроенный микрошаг не более 0.025 мм. Для известных осей проверки сохраняются.
- `allow_during_print` требуется для воспроизведения из задания печати,
  в том числе с `PRE_HOME=1`.
- Только Cartesian. Оси с независимыми драйверами нескольких моторов отклоняются.
  Два мотора на одном драйвере видны как один шаговик, но их механику и звук
  всё равно нужно проверять отдельно.
- Реверсы создают заметный поток команд MCU. Лимит шагов не гарантирует
  достаточную пропускную способность UART/USB/CAN. Рост амплитуды увеличивает
  и движение, и поток команд.
- Ошибка после начала низкоуровневой генерации переводит Klipper в shutdown,
  чтобы печать не продолжалась после возможного неполного колебания. Обычная
  отмена не удаляет уже поставленные в очередь шаги немедленно; аварийная остановка — `M112`.

## Формат Bambu M1006

| Партия | Нота | Длительность | Громкость |
|---|---|---|---|
| X | `A` | `B` | `L` |
| Y | `C` | `D` | `M` |
| Z | `E` | `F` | `N` |

Ноты 1–72 соответствуют MIDI `note + 23`: 37 — C4, 46 — A4. Ноль — тишина.
Длительность задаётся целыми сотыми секунды: `D20` = 200 мс. Партии одной
строки начинаются одновременно; строка длится по самой длинной партии.
Пропущенная партия в отрезке молчит. Громкость 0–100 сохраняется до нового
значения; ноты и длительности не сохраняются.

```gcode
M1006 S1
M1006 C46 D20 M100
M1006 C0 D10
M1006 C49 D20 M100
M1006 W
```

В напрямую вставляемой последовательности должны быть только строки `M1006`.
Загрузка файлов также допускает известную обвязку: `M17` без параметров,
`M18` с буквами осей, `M400` / `M400 S1` и метаданные `M73 P… R…`, не выполняя
их. Команды движения, нагрева, тока моторов, несколько последовательностей,
неверные параметры и незавершённые файлы отклоняются. Пределы: 128 КиБ,
1024 накапливаемые строки данных/настроек, 200 сотых секунды на партию
в отрезке и заданное ограничение общей длительности.

## Частые вопросы

| Симптом | Что проверить |
|---|---|
| С `VOICES=X` всего три ноты | Это исходная партия X у A1. Для ведущей мелодии выбирай Y, для всей аранжировки — XYZ. |
| «Voice … is not configured» | Для семи комбинаций нужен полный профиль. В профиле одного мотора доступен только Y. |
| «Home XYZ» / «must already be enabled» | Сделай homing и парковку либо явно используй `PRE_HOME=1` для короткой мелодии из файла до homing. |
| «Park … away from its limits» | Играй до парковки на границе, сохраняя отступ и запас на колебания. |
| «Music during a print is disabled» | Установи `allow_during_print: True` и перечитай конфигурацию на свободном принтере. |
| «Combined step rate … exceeds …» | Для трёхголосных штатных мелодий нужен лимит 3000 из полного профиля. Рост амплитуды может потребовать большей пропускной способности. |
| Новый код не подхватился | Перезапусти службу Klipper, а не только выполни G-code `RESTART`. |
| Разная громкость или тарахтение | Одинаковая амплитуда не означает одинаковую громкость. Сравни голоса отдельно; компенсация под конкретный принтер не реализована. |

При амплитуде 1 все ненулевые уровни округляются до одного микрошага.
Громкость регулируется грубо, без акустической калибровки. Частотные резонансы
мотора и рамы и разная механика влияют на звук; таблицы Bambu для других
принтеров не переиспользуются.
